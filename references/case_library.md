# 改写案例库

> Agent 做深度改写时参考本文件的处理思路，不要照搬——理解改写逻辑后灵活运用。

## 一、博客/公众号长文（blog）

### 案例 1：三段论 → 自然推进

**改写前**：
"首先，我们需要了解用户需求。其次，分析竞品的优势和劣势。最后，结合自身资源制定差异化策略。综上所述，差异化是赢得市场的关键。"

**改写后**：
"了解用户需求是第一步，但别急着做——先看看对手在干什么、哪里做得好、哪里空了。看清楚了，再回头掂量自己的家底。能打的牌就那么多，挑一张别人没有的。"

**改写逻辑**：破"首先/其次/最后/综上所述"四层壳 → 用"第一步→但别急→再回头"的自然推进替代 → 结尾用具体动作替代升华

**MLS 标注**：核句(能打的牌就那么多，挑一张别人没有的。13 字) / 卫句(先看看对手在干什么、哪里做得好、哪里空了。20 字) / 衔接句(了解用户需求是第一步，但别急着做。14 字)

### 案例 2：AI 热词堆砌 → 大白话

**改写前**：
"通过底层逻辑的拆解，可以发现这套系统实现了全链路的数字化赋能，形成了数据驱动的闭环生态，重构了行业的底层范式。"

**改写后**：
"拆开看，这套系统做的事其实很简单：从头到尾把数据打通了。以前每个环节各管各的，现在数据跑了一圈能接上——这圈跑通了，整个行业做事的方式就变了。"

**改写逻辑**：底层逻辑→拆开看 / 全链路→从头到尾 / 赋能→把数据打通 / 闭环→跑了一圈能接上 / 生态→删 / 底层范式→做事的方式

**MLS 标注**：核句(整个行业做事的方式就变了。12 字) / 卫句(以前每个环节各管各的，现在数据跑了一圈能接上。21 字)

## 二、小红书/微博短文（social）

### 案例 3：教科书式种草 → 真人分享

**改写前**：
"你有没有想过，为什么你的皮肤总是暗沉？值得注意的是，这可能与你的护肤步骤有关。首先，清洁不彻底会导致毛孔堵塞。其次，保湿不足会使皮肤失去光泽。最后，防晒不到位会加速皮肤老化。所以，从今天开始做好这三步，让你的皮肤焕发光彩！"

**改写后**：
"皮肤暗沉？我踩了三年的坑终于搞明白了。洗脸洗不干净——堵了。水没补够——干了。防晒偷懒——老了。三件事，没一件能偷懒。我现在每天多花 10 分钟，素颜出门也有人问擦了啥。"

**改写逻辑**：去设问开头 → 直接抛痛点 / 去"首先/其次/最后" → 三句短句连击 / 去升华结尾 → 结局落在"有人问擦了啥"这个具体结果上 / 加"我"视角

### 案例 4：空洞推荐 → 细节锚点

**改写前**：
"这款面膜非常好用，效果非常明显，值得推荐。它的成分非常安全，使用感非常舒适，价格也非常合理。"

**改写后**：
"这个面膜，我敷了三次就感觉不一样——不是那种即时假白，是第二天起来脸还是亮的。查了成分，烟酰胺排第三，不是概念添加。膜布也薄，贴在脸上不滴液，刷手机不用擦屏幕。一盒 89，比我之前用的 200 块的强。"

**改写逻辑**：五个"非常"全删 → 每个换成具体细节（敷三次/烟酰胺排第三/不滴液/89 元 vs 200 元）

## 三、知乎回答（zhihu）

### 案例 5：百科词条腔 → 从业者视角

**改写前**：
"在当今数字化转型的浪潮中，AI 技术在医疗领域的应用日益广泛。研究表明，AI 辅助诊断在某些场景下可以达到甚至超过人类专家的水平。值得注意的是，这一趋势正在深刻地改变传统的医疗模式。总的来说，AI 与医疗的结合具有广阔的前景。"

**改写后**：
"三年跟了 40 多个医院的 AI 部署项目，说点实在的。AI 辅助诊断确实能打——尤其在影像这块，肺结节的检出率我们这边跑下来比高年资医生高 12%。但不是没有坑：数据质量差的话，模型就是垃圾进垃圾出。前景是好，但别只看前景。"

**改写逻辑**：去全知视角 → 加"我跟了 40 多个项目" / 去"研究表明" → 给具体数字(高 12%) / 删"值得注意的是/总的来说" → 自然转折 / 加从业者判断("不是没有坑")

## 四、朋友圈/口语化（casual）

### 案例 6：AI 生成的日常 → 真人碎碎念

**改写前**：
"今天去了新开的咖啡店，环境十分优雅，服务非常周到，咖啡的口感醇厚，回味无穷。总体来说是一次非常愉快的体验，强烈推荐给大家！"

**改写后**：
"新开的咖啡店。环境还行吧，人少，适合发呆一个小时。咖啡比我预期好——入口不酸，回甘真的有。花了 35，值。下次带电脑来。"

**改写逻辑**：去全知评价 → 去"十分优雅/非常周到" / 碎句化 → 8 句短句 / 加个人判断("还行吧""比我预期好""值") / 删总结段

## 五、商务/正式文档（business）

### 案例 7：AI 腔报告 → 专业不冰冷

**改写前**：
"本季度，我司在市场拓展方面取得了显著成效。通过多维度的渠道整合与系统性的资源优化，实现了客户触达效率的全面提升。值得注意的是，新客户的转化率较上季度提升了 35%，这在某种程度上验证了我们的战略方向的正确性。综上所述，下一阶段应继续深化现有渠道，同时探索新的增长点。"

**改写后**：
"本季度市场拓展的核心数据：新客转化率环比提升 35%。背后是三件事做对了——渠道整合把重复覆盖砍掉 20%，投放策略从广撒网改成精准定向，销售团队的跟进速度从 24 小时压缩到 4 小时。下季度：把这三件事做深，同时试水两个新渠道（方案见附件）。"

**改写逻辑**：保留正式语体 / 去"取得了显著成效" → 给数据 / 去"值得注意的是/综上所述" → 直接说 / 结尾用"下一步行动"替代"深化/探索"

## 六、MLS 节奏对比

### 案例 8：均匀段落 → 节奏重构

**改写前**（每句 18-22 字，节奏均匀）：
"用户留存率的下降反映了产品体验的问题。(18 字) 我们需要从交互设计和内容质量两个维度进行优化。(20 字) 数据显示新用户的次日留存率仅为 35%。(19 字) 这一指标距离行业平均水平还有较大差距。(18 字) 建议在下一个版本中优先解决新手引导的问题。(20 字)"

**改写后**（长短交错，核句锚点）：
"留存率掉了。(4 字——衔接句) 35%。(2 字——强调) 行业平均 50%。(6 字——核句) 差这 15 个点，说明产品体验出了问题——新用户进来不知道该干嘛，交互设计和内容质量都有坑，得从新手引导开始修。(38 字——卫句) 下个版本先动这块。(7 字——核句)"

**改写逻辑**：核句(35%/先动这块)分别放在段落头和尾锚点 → 卫句(38 字)承载全部论证细节 → 最短句 2 字 vs 最长句 38 字 = 1:19，远超过 1:2.5 底线

## 七、学术/技术论文（academic）

### 案例 9：AI 腔论文 → 去壳不去骨

**改写前**：
"在当今人工智能技术快速发展的背景下，深度学习模型在自然语言处理领域取得了显著突破。本研究基于Transformer架构的底层逻辑，通过多维度的实验设计与系统性的评估方法，深入探讨了大语言模型在知识推理任务中的表现。值得注意的是，实验结果表明，该模型不仅在某些特定任务上超越了传统方法，更是在复杂推理场景中展现出令人瞩目的能力。从本质上来看，这种认知能力的提升标志着AI技术在范式转移层面迈出了关键一步。综上所述，大语言模型的知识推理能力正在深刻地重塑着AI研究的基本范式。"

**改写后**：
"深度学习在自然语言处理领域近年来进展显著。本研究基于Transformer架构，通过多维度的实验设计与系统性的评估方法，考察大语言模型在知识推理任务上的表现。实验结果显示，该模型在特定任务上超越了传统方法，在复杂推理场景中也表现突出——这意味着AI在范式层面的认知能力正在发生变化。大语言模型的知识推理能力，正在推动AI研究基本范式的演进。"

**改写逻辑**：
- 去开场套话："在当今…背景下" → 直接入题（学术允许去这类开场）
- 去全场景热词："底层逻辑"（🔴全场景热词，学术不豁免）、"显著突破"（空洞→"进展显著"）
- **保留学术常用词**："多维度"（🟢豁免）、"系统性"（🟢豁免）、"范式"（🟢豁免）、"深入探讨"→"考察"（保留语义但精简）
- 破句式壳："值得注意的是"→删、"不仅…更是…"→破壳、"从本质上来看…标志着"→拆壳
- 降判断强度："深刻地重塑"→"推动演进"、"令人瞩目"→"表现突出"
- 去模板收尾："综上所述"→删，结尾落回具体判断

**MLS 标注**：核句(深度学习在自然语言处理领域近年来进展显著。16 字) / 卫句(本研究基于Transformer架构，通过多维度的实验设计与系统性的评估方法，考察大语言模型在知识推理任务上的表现。38 字) / 核句(大语言模型的知识推理能力，正在推动AI研究基本范式的演进。24 字)

**关键差异**：同段文本在 blog 场景下会被诊断为 52 分（中度 AI 味），"范式/多维度/系统性"全部当热词删除；在 academic 场景下仅 33 分（轻度），这些学术常用词全部保留。改写后 blog 版会变得口语化、丢失方法论细节；academic 版仅去壳、保留完整学术骨架。
