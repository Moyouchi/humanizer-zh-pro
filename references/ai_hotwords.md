## 一、AI 热词（按严重度分级）

### 🔴 重度（几乎只在 AI 文本中出现）

| 热词 | 典型搭配 | 替换思路 |
|------|---------|---------|
| 赋能 | "科技赋能""AI赋能""为行业赋能" | 换成具体动作："帮""让……变快""给……加了个工具" |
| 底层逻辑 | "底层逻辑是……""拆解底层逻辑" | 删或换："说白了""实际上""根源在于" |
| 闭环 | "形成闭环""商业闭环""生态闭环" | 删或用大白话："转一圈能接上""从头到尾跑通" |
| 抓手 | "核心抓手""主要抓手" | 删或换："切入点""关键动作""靠什么" |
| 颗粒度 | "颗粒度很细""提升颗粒度" | 删或换："细到""做到……级别" |
| 范式转移 | "带来范式转移""产业范式转移" | 删或换：用具体转变描述替代 |
| 链路 | "全链路""链路打通" | 删或换："从头到尾""整个流程""一连串" |
| 组合拳 | "打出组合拳""一套组合拳" | 删或换："多管齐下""几招一起上" |

### 🟡 中度（AI 高频但人类偶尔也用，看密度）

| 热词 | 使用阈值 | 处理 |
|------|:------:|------|
| 矩阵 | 同段 ≥2 次 | 删或换："一系列""一整套" |
| 赛道 | 非商业场景中出现 | 删或换："方向""领域" |
| 维度 | 同段 ≥2 次 | 删或换："方面""角度" |
| 生态 | 非自然生态语境 | 删或换："环境""圈子""系统" |
| 重塑/颠覆 | 无具体机制支持 | 删或弱化："改变很大""动摇了" |
| 迭代 | 非技术语境 | 删或换："更新""改进""一轮一轮改" |
| 深耕/精耕 | — | 删或换："一直在做""专注做" |
| 落地 | 同段 ≥2 次 | 删或换："执行""做出来" |

### 🟢 轻度（本身正常，AI 密度异常）

| 热词 | 使用阈值 | 处理 |
|------|:------:|------|
| 系统性 | 同段 ≥2 次 | 保留 1 次，其余删 |
| 高效/稳健/可持续 | 连续出现 | 保留 1 次，其余具体化 |
| 驱动 | 同段 ≥2 次 | 换："推动""带动" |
| 深度 | 修饰无实质内容 | 删修饰："深度分析" → "分析" |

## 二、句式壳（AI 偏好的句式模板）

### 二元对立壳

| 句式 | 示例 | 改写 |
|------|------|------|
| 不是 A 而是 B | "不是技术问题，而是人的问题" | 保留对比但破句式："说到底，是人的问题" |
| 不仅是 A 更是 B | "不仅是工具，更是思维延伸" | 删升华："它就是你的思维延伸" |
| 不在于 A 而在于 B | "不在于资源多少，而在于会不会用" | 直接说 B："会不会用，比资源多少重要" |
| 与其说 A 不如说 B | "与其说是创新，不如说是改良" | 直接下判断："这更像改良，不是创新" |

### 分步序列壳

| 句式 | 示例 | 改写 |
|------|------|------|
| "首先/其次/最后" | "首先看 A。其次看 B。最后总结" | 删序号，用语义推进："A 是这样。B 那边呢，……" |
| "第一步/第二步……" | "第一步分析。第二步方案。第三步执行" | 合并不分步 |
| "先 A 再 B" | "先理解需求，再设计方案" | 自然叙述 |

### 本质论断壳

| 句式 | 示例 | 改写 |
|------|------|------|
| "真正重要的是……" | "真正重要的是用户体验" | 删引导："用户体验。没有这个，别的都白搭" |
| "本质上……" | "本质上，这是一种信任问题" | 直接说 |
| "核心在于……" | "核心在于数据和算法" | 直接说 |
| "说到底……" | 正面使用（非模板化时 OK） | — |

### 解说导引壳

| 句式 | 示例 | 改写 |
|------|------|------|
| "值得注意的是……" | — | 删，直接说内容 |
| "不可否认的是……" | — | 删引导句 |
| "在这个过程中……" | — | 删介词框架 |
| "这背后的原因是……" | — | 删或缩："因为" |

### 劝诫收尾壳

| 句式 | 示例 | 改写 |
|------|------|------|
| "是不是很有启发？" | — | 删反问 |
| "你怎么看？欢迎留言讨论" | — | 删 CTA 壳 |
| "希望对你有帮助" | — | 删（AI 结尾标配） |
| "让我们一起期待" | — | 删或换成具体预测 |

## 三、翻译腔模式

| 模式 | 识别 | 改写 |
|------|------|------|
| "在……的过程中" | 英文 while/during 从句的直译 | 删介词框架："分析过程中发现" → "分析发现" |
| "基于……而……" | 英文 based on 直译 | "基于数据" → "根据数据" |
| "被……所……" | 英文被动语态的过度直译 | "被广泛使用" → "用得很广""大家都在用" |
| "对于……而言" | 英文 for 从句直译 | "对于初学者而言" → "对初学者来说" |
| "使得/得以/使之" | 英文 enable/make/allow 直译 | "使得它能处理" → "能处理" |
| "作为一个……" | 英文 as a… 直译 | "作为一个工具" → "这工具" |
| "它能够/它可以" | 英文主谓不省略习惯 | 能删就删："能处理" |

## 四、空洞修饰词

| 词 | 处理 |
|----|------|
| 非常/十分/特别 + [形容词] | 删程度副词，或换成具体原因 |
| 重要的/关键的 | 删或具体化："重要到你错过这一步后面全白做" |
| 不可或缺的 | 删 |
| 不可忽视的 | 删或给出忽视的后果 |
| 出乎意料 | 删或给出具体意外的点 |
| 堪称/可谓 + [评价] | 删引导词 |

## 五、标点 AI 味模式

| 模式 | 识别阈值 | 处理 |
|------|:------:|------|
| 破折号过密 | 每千字 >5 个 或 段落覆盖率 >60% | 非必需的用逗号/句号替；同类功能用不同标点 |
| 粗体轰炸 | 加粗词占比 >10% 或被加粗的是普通词 | 仅保留术语、关键词的加粗 |
| 冒号解释链 | 连续 ≥3 句靠冒号展开 | 打破解释链，改用独立句 |
| 编号切碎 | 同段 ≥5 个编号项 | 改成自然叙述或精简列表 |
